# Documentation

This directory contains the living technical documentation for StockPilot AI.

- `architecture.md`: system boundaries and architectural principles
- `advanced-features.md`: portfolio, PDF, and investment-journal workflows
- `database.md`: PostgreSQL tables and ORM ownership rules
- `development.md`: local development workflow and environment setup
- `api-conventions.md`: baseline HTTP API conventions
- `deployment.md`: Docker deployment, upgrades, backups, and troubleshooting

Architecture decisions that materially change the system should be recorded here before implementation.
